# ZG-Schlaglänge

iPhone-App von Zulu Golf, die per GPS misst, wie weit du mit jedem Schläger schlägst.

- Schläger wählen, am Abschlag auf „Abschlag“ tippen, am Ball auf „Am Ball“.
- Jede Messung mittelt einige Sekunden GPS-Werte und zeigt die Unsicherheit (± m).
- Statistik mit Durchschnitt, Anzahl und weitestem Schlag pro Schläger.
- Alle Daten bleiben lokal auf dem iPhone.

## Projekt öffnen

`Schlaglaenge.swiftpm` in Swift Playgrounds (iPad/Mac) oder Xcode öffnen. Ab iOS 16, nur iPhone im Hochformat.
